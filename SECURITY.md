# Security Policy

We take security and private user financial data seriously. Thank you for helping us keep Monerva safe.

---

## 🛡️ Supported Versions

We actively support and patch security issues in the following versions:

| Version | Supported |
| :--- | :--- |
| **v1.3.0** |  Yes (Current Active Branch) |
| < v1.2.0 |  No |

---

## 🔒 Reporting a Vulnerability

**Please do NOT open a public GitHub issue for security vulnerabilities.**

If you have discovered a vulnerability (SQL injection, XSS leaks, privilege escalation bypasses, or secret exposures), please report it privately:

1. Send an email to **security@example.com** with details of the vulnerability.
2. Include a proof of concept (PoC) with instructions on how to reproduce the issue safely.
3. We will acknowledge your report within **24 hours** and coordinate a patch schedule.

We practice responsible disclosure and appreciate your cooperation in keeping disclosures private until a patch is released.
