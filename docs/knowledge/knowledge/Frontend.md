# Frontend

Related: [[Dashboard]], [[API]], [[Authentication]]

Tags: #react #vite #ui

Vite SPA powered by React 19 and TypeScript:
* State: Zustand (`authStore.ts`) for auth, TanStack Query for background REST fetching.
* Styles: TailwindCSS v4 with custom HSL properties.
* Pages map routes for landing, workspace panels, tables, and settings.
