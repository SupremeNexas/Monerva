# Dashboard

Related: [[Transactions]], [[Analytics]], [[Wallets]], [[Credit Cards]]

Tags: #ui #dashboard #workspace

The primary workspace view for users after signing in. It aggregates all personal finance data into high-contrast spring cards and charts:
* **Spend Meters**: Circular rings tracking budget consumption levels.
* **Category Distributions**: Pie charts mapping spending share percentages.
* **Monthly Trends**: Area charts displaying transaction timeline trends.
* **AI Floater**: Handles receipt OCR scanning requests and mounts the conversational AI Coach drawer.
