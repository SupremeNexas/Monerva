### 2. Third-Party AI Data Processing & Architecture

2.1 **Google Gemini API Integration:** Receipt scanning and conversational assistant features transmit relevant image payloads and query contexts over encrypted TLS channels to Google's Gemini Cloud API endpoints. Data handling and retention policies are governed by Google's API Privacy Terms applicable to the API tier (paid Cloud vs free Studio tier) enabled by the deployment operator.

2.2 **In-Process Vector Embeddings:** Document search features compute 384-dimensional vector embeddings locally on the backend server using the `@xenova/transformers` library. Vector embeddings are stored in the PostgreSQL database within the user's account scope and are not transmitted to external third-party vector index services.

2.3 **Tenant Isolation & Context Scrubbing:** Prompt inputs and RAG context blocks are formatted within the authenticated user's `userId` and `workspaceId` context. Input text is scrubbed of known prompt injection patterns prior to model evaluation.
